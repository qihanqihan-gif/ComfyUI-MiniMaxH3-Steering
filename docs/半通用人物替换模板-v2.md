## 二、占位符清单与填充指南

| 占位符 | 含义 | 填充要点 |
|---|---|---|
| `[发型与发色]` 等身份项 | 新角色视觉特征 | 全部来自识图/参考图，**不得从参考视频原人物推断** |
| `[特征1/2/3]` | HARD LOCK 身份关键特征 | 只锁 3-5 项身份关键（光环/翅膀/异色瞳等），每项含：是什么/数量/位置/永不发生/遮挡行为；**不锁姿势/表情**（Over-Prompt 纪律） |
| `[如果是三视图/设定图]` | 多视图声明 | 有设定图必加「one single character only」句；无则删除 |
| `[可选] <Picture 2/3>` | 脸部/全身参考 | 有对应接线图才保留；提示词引用数 = 实际接线数 |
| `[目标视频结束时间]` | 时长 | 单段 ≤15s（2fps 抽帧边界，360 帧对齐） |
| `[Shot N — 时间戳]` | 真实分镜 | 只写真观测时间戳；未分析视频则删分镜改用整段转移语言 |
| `[节拍/动作时机...]` | 音频用途 | 保留原音频改 copied/preserved；只参考节拍写 reference |
| soundscape/music 三选一 | 音频模式 | 保留原音频 / 只参考节拍 / 自生成（H3 环境音） |

**变体开关**：
- `{BG_MODE}`：preserve（默认，背景保留）——正文即 preserve 版；redraw（背景重绘）——把 detailed_description 背景句换成新场景描述（少数需求）
- `{AUDIO_MODE}`：原音频保留 / 节拍参考 / 自生成——对应 soundscape 三选一 + ref_audio 接线
- **动作粒度**：标准（默认，2fps 抽帧边界内）/ 动作强调（对关键动作多写过程动词与身体反应，仍在 2fps 上限内）/ 逐帧级（**超出 H3 能力**——需换动作迁移管线如 Wan SCAIL 类，不要用本模板硬扛）
- 分段：单段 ≤15s；长参考视频按 15s/段切片（`skip_first_frames` 偏移）+ 交叉淡化拼接

## 四、使用注意事项（生成前逐条过）

1. **接线一致性**：提示词引用的 `<Picture N>` 数量 = 实际 ref_image_N 接线数（图-标签一一对应；3 图只接 1 图 → 替换必然失败）
2. **防复刻措辞**：全文禁用「逐帧执行/完整复刻/继续/延续」；summary 必须 `[reference generation]` 前缀；整段转移语言不得以 Continue 开头
3. **不描述原人物**：原人物只出现在 retention 的 DO NOT PRESERVE 否定句
4. **背景保留靠双保险**：retention 双层声明 + detailed_description 背景句引用 `<Video 1>`，缺一不可（自编新场景 = 背景重绘）
5. **transcribe 保护**：若经 LLM 改写管道，整段模板放 `[[原文块]]` + transcribe 档强制保原文
6. **换角色必须清残留条款（00084 实证，2026-08-18）**：模板通用化/换参考图时，全文检索上一角色的专属特征条款（翅膀/光环/异色瞳/发色服装等 HARD LOCK 与「贯穿整个视频」列表），必须删除或改为新角色对应项——实测模板残留「恰好一只黑色恶魔翅膀」条款 + 换无翅膀角色（CH0066）→ 模型脑补出翅膀/银白发 → 身份漂移（00084，qwen+gemma 双模型互证）。占位符版 HARD LOCK 只留 3-5 项当前角色特征。
7. **期望管理**：H3 软参考边界（Qwen 通道 2fps 抽帧）——动作骨架可能简化；背景保留成功率高于动作逐帧一致
