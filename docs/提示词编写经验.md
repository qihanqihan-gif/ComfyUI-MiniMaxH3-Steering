# 提示词编写经验（社区 357 条 + GPT 5.6 核验 + 实测）

> 经验来源于：社区提示词库（awesome 222 条 + stunning 135 条）、MiniMax 官方 skill、GPT 5.6 两轮深度分析核验、本插件实测。供手写 H3 提示词与扩展模块时参考。

## 一、图生视频（I2VA）最常见的需求与写法

### 静态锚定 + 细微动态（「静态图活化」）
- 写法：`static camera with subtle handheld breathing`（社区实证原文，见 charming-portrait 案例）
- 微动清单：发丝/衣角轻摆、眨眼与呼吸、水面涟漪、云漂移、灯光微闪、尘埃漂浮
- 防漂移负面：`no camera movement, no subject movement, no scene morphing, no perspective shift`

### 缓慢推进（氛围感）
- `single slow push-in toward the subject`，幅度限定 subtle/gradual
- 推进同时保留主体微动态，避免「死画面推镜」

### 动态壁纸
- 首尾帧完全闭环（同构图/光照/姿态）、慢速氛围动效、竖屏 9:16、单镜无切
- 负面：`no jump cut, no visible loop seam, no flickering light`

### 视差分层（静帧活化进阶）
- 前景/中景/背景分速度横移（前景最快），每层保留微动防「纸片感」

## 二、人物一致性

1. **参考图管身份，提示词管动作**（Ref2VA 铁律）
2. 双人/多人：每人独立 `(S1)/(S2)` 绑定各自 `<Subject N>`，写清空间关系（站位/距离/视线）
3. 负面：`no character swapping, no merged bodies`（多人必带）

## 三、动作与物理

- 一个主动作 + 起止帧（起始姿态→发力瞬间→落点）
- 速度感词汇：swift / powerful / fluid / weightless
- 二次运动（secondary motion）：布料/头发/尘土随动作反应
- 负面：`no physics glitches, no morphing limbs`

## 四、声音与配乐

- 环境声分层写（room tone + 具体动作声），配乐克制
- 配乐写构成不写情绪：乐器 + BPM + 节奏 + 动态
- 完全静音才写 N/A；剧情内音乐归主字段

## 五、常见坑（实测/社区高频）

| 坑 | 对策 |
|---|---|
| 画面漂移/场景渐变 | 静态锚定模块 + 负面约束成句 |
| 角色换装/换脸 | 锁定五官/发型/配色，负面 no outfit change |
| 文字乱码 | 逐字保留原语言 + 双引号 + 负面 no random letters |
| 循环跳变 | 首尾帧状态一致 + no jump cut |
| 配乐喧宾夺主 | non_diegetic_music 写具体构成 + 音量相对环境声 |
| 时间码超界 | 分镜时间码 ≤ 总时长（插件 h3_compiler 自动查） |

## 六、怎么写你自己的模块（30 秒版）

1. 复制任意 `modules/*.json` 改名
2. `instructions` 里写：你的风格/场景要求 + 负面约束
3. 换行写成 `\n`（JSON 不能有裸换行）
4. 放进 `modules/` 即热加载生效，无需重启
